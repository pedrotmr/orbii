## MCP scopes

| Scope         | Tools / capability                                                                                                                                   | Data exposed or mutable                                                                                                                                                                                                                                                                                                                          |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `orbii:read`  | `get_orbit`, `get_today`                                                                                                                             | Full Orbit habit list; today’s phase, offer, selections, commitment, completion state                                                                                                                                                                                                                                                            |
| `orbii:write` | `start_today`, `rereveal_today`, `select_habit`, `deselect_habit`, `commit_today`, `complete_habit`, `uncomplete_habit`, `add_habit`, `remove_habit` | Mutates ritual and Orbit per Spec V2 / backend rules; write grant = no per-action Orbii confirm. `complete_habit` / `uncomplete_habit` write or reverse habit point transactions (and can add/remove the completion bonus). `remove_habit` does not reverse awards; if removal completes an open day, it can add a completion-bonus transaction. |

No dedicated MCP tools for editing point values, creating rewards, or redeeming rewards. Also out of MCP scope: habit edit/reorder (beyond add/remove), account settings, other product actions.

Consent UX: Clerk OAuth consent identifies client + requested scopes; Settings lists connections for independent revocation.

## What we do not collect (current build)

- Third-party mobile analytics / ad SDKs (none in `apps/mobile` dependencies for that purpose)
- Remote push tokens for daily reminders
- Precise location
- ATT tracking / advertising ID for ads
- HealthKit / clinical data APIs
- Social graph or contacts
